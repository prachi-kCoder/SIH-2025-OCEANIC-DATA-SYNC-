# 🌊 Aquanex — SIH 2025 Finalist Project

🚀 **Smart India Hackathon (SIH) 2025 Finalist**  
Aquanex is a full‑stack solution designed to integrate **oceanic data providers** with scalable web applications, enabling real‑time insights into marine ecosystems.  

---

## 🏆 Achievement
- Selected as a **Finalist at SIH 2025**, representing innovative solutions in oceanic data science.  
- Recognized for combining **AI/ML, FastAPI, and MERN stack** to deliver a robust, production‑ready system.  

---

## 💡 Project Overview
Aquanex bridges multiple marine data sources (NOAA, WORMS, Open‑Meteo, OBIS) into a unified platform.  
Key features:
- 🌐 **Data Integration:** Fetch and process real‑time oceanic data.  
- 📊 **Visualization:** Interactive dashboards powered by ReactJS.  
- ⚡ **High‑Performance Backend:** FastAPI for scalable APIs.  
- 🔒 **Reliability:** Secure, modular architecture with cloud‑ready deployment.  

---

## 🛠️ Tech Stack
- **Frontend:** ReactJS, Redux, NextJS  
- **Backend:** FastAPI, Node.js, Express  
- **Databases:** MongoDB, SQL, Redis  
- **Languages:** Python, C++, JavaScript (ES6+)  
- **Cloud & DevOps:** AWS (EC2, S3, Lambda), Docker, Firebase Hosting  

---

## 📂 Project Setup

### Frontend (ReactJS)
```bash
cd OcenicSIH2025/client/frontend
npm install
npm run dev
```
### BACKEND
```bash
cd server
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload
```
